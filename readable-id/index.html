05 · Get started

Drop it in. Name things.

One file, zero dependencies, Node 18+ and every modern browser. TypeScript types included.

1Install

Straight from GitHub. Nothing else comes with it.

npm i github:ghanemja/readable-id

2Generate

Sensible defaults, every knob optional.

import { readableId } from 'readable-id';

readableId();                // 'brave-otter-42'
readableId({ words: 3 });    // 'misty-gentle-heron-07'
readableId({ separator: '_', digits: 4 });
                             // 'lucky_comet_3810'

3Know your odds

Size the space before it bites.

import { combinations, collisionProbability,
         isReadableId } from 'readable-id';

combinations();               // 6374400
collisionProbability(1000);    // ≈ 0.075
isReadableId('brave-otter-42'); // true
