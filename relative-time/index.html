      02 · Units & thresholds

      When does “59 minutes” become an hour?

      The difference is rounded in each unit, smallest first, and the first unit whose rounded value is below its limit wins. These switch points are found live by bisecting the library's own selectUnit.

          Install

          From GitHub:

          npm i github:ghanemja/relative-time

          Or copy the ~50-line index.js into your project.

          Format a date

          Dates, timestamps or ISO strings. Past and future both work.

          import { relativeTime } from 'relative-time';

relativeTime(Date.now() - 3 * 60e3);   // "3 minutes ago"
relativeTime(Date.now() + 2 * 864e5);  // "in 2 days"
relativeTime(Date.now() - 864e5, { locale: 'de' });
// "gestern"
relativeTime(Date.now() - 864e5, { locale: 'de', numeric: 'always' });
// "vor 1 Tag"

          Reuse options, or just the unit

          Bake in defaults, override per call, or take the unit picker alone.

          import { createFormatter, selectUnit } from 'relative-time';

const ago = createFormatter({ locale: 'fr' });
ago(Date.now() - 2 * 3600e3);          // "il y a 2 heures"
ago(Date.now() - 2 * 3600e3, { style: 'short' });

selectUnit(-90);  // { value: -2, unit: 'minute' }
