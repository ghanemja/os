        validateEnv(schema, env)
        
Nine types. Strings in, real values out.

        
Environment variables are always strings. Each type parses and checks them, so config.PORT is a number and config.DEBUG is a boolean. Type in any box.

        get started
        
Zero dependencies. Node 18+.

        
Types infer the config shape from your schema, so config.PORT is a number in your editor too.

        

          

            01 · install
            
Add it

            
npm i github:ghanemja/env-check

            
One runtime file plus a CLI. No dotenv needed.

          

          

            02 · validate at startup
            
Typed config, or a clear exit

            
import { checkEnv } from 'env-check';

const config = checkEnv({
  PORT: { type: 'port', default: 3000 },
  DATABASE_URL: { type: 'url', required: true },
  MODE: { type: 'enum', values: ['dev', 'prod'] },
}, { dotenvPath: '.env', exit: true });

config.PORT; // 3000, a number

          

          

            03 · gate your deploys
            
Run the CLI before start

            
// package.json
"scripts": {
  "prestart": "env-check",
  "start": "node server.js",
  "env:example": "env-check --example"
}

          

          

            04 · browser & edge
            
Just the parser and validator

            
// no node: imports, runs anywhere (this page uses it)
import { parseDotenv, validateEnv, formatErrors }
  from 'env-check/core';

const { config, errors } = validateEnv(schema, parseDotenv(text));
if (errors.length) console.error(formatErrors(errors));
