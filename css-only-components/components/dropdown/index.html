Accessibility notes

  • This is a disclosure (a button that shows a list of links), not an ARIA menu. Users Tab through the items, and arrow keys do nothing. That fits navigation links. A real application menu needs JavaScript.
  • It does not close when you click outside or press Esc; activate the summary again to close it. For light-dismiss without JavaScript, use the popover approach instead.
  • The menu is positioned absolutely, so it can be clipped by an ancestor with overflow: hidden.
