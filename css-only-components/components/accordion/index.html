Accordion

Expandable sections built on details and summary, with optional one-open-at-a-time grouping. No JavaScript.

What is this?
A collection of components that need no JavaScript.
Does it work with a keyboard?
Yes. Tab to a question and press Enter or Space.
Can several be open at once?
Remove the shared name attribute and they can.

Accessibility notes

  • Native <details>/<summary> gives keyboard support (Enter/Space) and announces expanded or collapsed state for free.
  • Give every <details> the same name to allow only one open at a time. Browsers without support simply allow several open.
  • Find-in-page (Ctrl+F) opens matching closed sections in Chromium browsers. Do not put headings inside <summary>; some screen readers then drop the heading role.
  • The open/close animation uses ::details-content where supported and is turned off for reduced motion.
