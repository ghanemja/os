Toggle switch

A real checkbox with role="switch", styled as an on/off switch. No JavaScript.

Accessibility notes

  • Built on a native <input type="checkbox" role="switch">, so it is focusable, toggles with Space, and screen readers announce it as a switch that is on or off.
  • The visible text inside the <label> is the accessible name. Do not leave it out.
  • In forced-colors (Windows High Contrast) mode the track gets a border and system colors.
