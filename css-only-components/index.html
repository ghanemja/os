Accordion

Expandable sections built on details and summary, with optional one-open-at-a-time grouping.

What is this?
A collection of components that need no JavaScript.
Does it work with a keyboard?
Yes. Tab to a question and press Enter or Space.
Can several be open at once?
Remove the shared name attribute and they can.

Open demo and accessibility notes

HTML

<div class="cc-accordion">
  <details name="cc-faq" open>
    <summary>What is this?</summary>
    <div class="cc-accordion__body">A collection of components that need no JavaScript.</div>
  </details>
  <details name="cc-faq">
    <summary>Does it work with a keyboard?</summary>
    <div class="cc-accordion__body">Yes. Tab to a question and press Enter or Space.</div>
  </details>
  <details name="cc-faq">
    <summary>Can several be open at once?</summary>
    <div class="cc-accordion__body">Remove the shared <code>name</code> attribute and they can.</div>
  </details>
</div>
