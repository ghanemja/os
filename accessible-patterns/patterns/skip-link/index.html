Skip link

A link at the very start of the page that takes keyboard users past repeated navigation and straight to the main content (WCAG 2.4.1, Bypass Blocks). It stays hidden until it gets focus.

Reload the page and press Tab once. "Skip to main content" appears in the top-left corner. Press Enter and the next Tab goes to the first link in the main content instead of the navigation.

Use transform or the .visually-hidden technique to hide it. Don't use display: none, because a hidden link can't be focused.

Related: Understanding SC 2.4.1 Bypass Blocks.
