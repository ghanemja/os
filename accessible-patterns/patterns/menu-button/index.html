Menu button

A button that opens a menu of actions. Use it for commands like "Duplicate" or "Delete". It is not for site navigation; a list of links works better there, with a disclosure if it needs to collapse.

  • Duplicate
  • Rename
  • Move (no folders)
  • Delete

Try it

  • Focus the button and press Down Arrow to open the menu on the first item, or Up Arrow to open it on the last.
  • Type r to jump to "Rename".
  • Escape closes the menu and returns focus to the button.

Follows the WAI-ARIA APG menu button pattern.
