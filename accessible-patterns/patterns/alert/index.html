Alert and live regions

Messages that screen readers announce without moving focus. role="status" (polite) waits until the user is idle. role="alert" (assertive) interrupts, so save it for urgent, time-sensitive messages.

Rules that make announcements reliable

  • Put the live region in the page before you need it. Adding an element that already contains text is often not announced.
  • Change the text content of the region. Don't toggle display on a region that already has text.
  • Repeating the same text is ignored, so nextAnnouncement() adds or removes a trailing non-breaking space to make each repeat a change.
  • Don't move focus to an alert. That's what dialogs are for.

Follows the WAI-ARIA APG alert pattern.
