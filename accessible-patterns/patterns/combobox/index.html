Combobox (autocomplete)

A text input with a list of suggestions that narrows as you type. Focus stays in the input. The highlighted option is tracked with aria-activedescendant, so screen readers read it out while you keep typing.

    Try it

    • Type "an" to see matches, with those that start with "an" first.
    • Down Arrow / Up Arrow move through the options, Enter picks one, Escape closes the list (press it again to clear the field).
    • Alt+Down Arrow opens the list without highlighting an option.

    Follows the WAI-ARIA APG combobox pattern (list autocomplete, no automatic selection).
