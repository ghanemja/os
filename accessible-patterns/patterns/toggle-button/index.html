Toggle button

A button with an on/off state, exposed with aria-pressed. Screen readers announce it as "toggle button, pressed" or "not pressed". The label stays the same; only the state changes.

The quick brown fox jumps over the lazy dog.

Don't change the label and aria-pressed together. "Mute" with aria-pressed="true" is clear. A button whose label flips between "Mute" and "Unmute" should not have aria-pressed, because "Unmute, pressed" is confusing.

Follows the WAI-ARIA APG button pattern (toggle button).
