Modal dialog

A window on top of the page. While it is open, keyboard focus stays inside it, the page behind it is inert, Escape closes it, and focus goes back to the button that opened it.

Try it

  • Open the dialog, then press Tab and Shift+Tab. Focus wraps around inside the dialog.
  • Press Escape or click the backdrop. Focus returns to "Edit profile".
  • With a screen reader, the page behind the dialog is unreachable while it is open.
