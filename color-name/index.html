    02 · How “close” is measured

    Distance the way eyes see it.

    RGB numbers are not how we perceive color: the same step can be invisible in one hue and obvious in another. CIEDE2000 (ΔE00) is the CIE's answer, and it is what color-name uses to pick a name.

    Try a pair

    1. Into CIELAB

      Hex becomes linear sRGB, then CIE XYZ (D65 white), then L*a*b*: lightness plus two opponent axes, roughly even to the eye.

    2. Weigh what matters

      Differences in lightness, chroma and hue are scaled separately, because we notice a hue shift in a gray far less than in a vivid color.

    3. Fix the blues

      A rotation term corrects Lab's known blue problem, where equal steps look unequal. The result is one number: ΔE00.

    4. Pick the nearest

      Your color is compared with all 354 names. The test suite checks the formula against all 34 reference pairs from Sharma et al. (2005).

      04 · Get started

      One file. No dependencies.

      Works in Node 18+ and every modern browser. ESM, typed, about 10 KB including all 354 names.

      Install

      Straight from GitHub (the npm name is taken by another package).

      npm i github:ghanemja/color-name

      Or copy index.js into your project. It has no imports.

      Name a color

      Live: this example uses the color you picked above.

      Nearest few, or your own math

      Get ranked matches, or use the Lab and ΔE helpers directly.

      import { nearest, hexToLab, deltaE2000 } from 'color-name';

nearest('#c05a20', 3).map(c => c.name);
// ['paprika', 'burnt orange', 'toffee']

deltaE2000(hexToLab('#0000ff'), hexToLab('#2020ff'));
// a small number: you'd need to look closely
