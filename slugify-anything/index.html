03 · Why not a one-liner?

        
Naive regex vs. slugify-anything

        
The classic /[^a-z0-9]+/g slugifier is fine until your first non-English title. Then it mangles words, drops whole languages and can hand you an empty string.

        

          
InputNaive replace(/[^a-z0-9]+/g, '-')slugify-anything

02Slugify

            
One function. Sensible defaults.


import { slugify } from 'slugify-anything';

slugify('Crème brûlée & café');
// → "creme-brulee-and-cafe"
slugify('I ❤️ NY 🚀');
// → "i-heart-ny-rocket"

          

          

            
03Tune it

            
Locales, length limits, custom rules, ASCII-only.


slugify('Müller', { locale: 'de' });  // "mueller"
slugify('C++ & C#', {
  custom: { 'C++': 'cpp', 'C#': 'csharp' }
});                              // "cpp-and-csharp"
slugify(title, { unicode: 'drop', maxLength: 60 })
  || fallbackId;
