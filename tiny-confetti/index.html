05 · Get started

Install. Import. Party.

No stylesheet, no canvas to set up. The canvas is created when a burst starts and removed when the last one ends.

  1. Install

    Straight from GitHub, or copy tiny-confetti.js into your project.

    npm i github:ghanemja/tiny-confetti

  2. Import

    One default export, plus the pure physics helpers if you want them.

  3. Celebrate

    await confetti() resolves when the burst has landed and the canvas is gone.

import confetti from 'tiny-confetti';

confetti();                                    // from the center
confetti({ origin: document.querySelector('#buy') });
confetti({ x: event.clientX, y: event.clientY, spread: 360 });

await confetti({ colors: ['#ff3d7f', '#ffc93c'], shapes: ['circle'] });
console.log('done, canvas removed');

import { resolveOptions, createRng, createParticles, stepParticle } from 'tiny-confetti';

// The physics are pure: no DOM needed, same seed = same burst.
const opts = resolveOptions({ count: 50, seed: 1 }, { width: 800, height: 600 });
let particles = createParticles(opts, createRng(opts.seed));
particles = particles.map((p) => stepParticle(p, 1 / 60, opts)); // one frame
