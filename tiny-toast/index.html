    03 · Accessibility

    Polite by default. Loud when it matters.

    Screen readers hear toasts through live regions, timers wait while you read, and every control is a real button. The inspector logs what each toast is doing, straight from the DOM.

    Status vs alert

    Info, success and warning use role="status" and wait for a pause. Errors use role="alert" and interrupt.

    Pause on hover & focus

    Fire a 6-second toast, then hover it or tab into it. The timer below mirrors the toast and freezes when it does.

    Waiting for a toast…

    Keyboard

    Focus never jumps to a toast on its own. Use this button to move focus into the newest one, then:

    • Tab moves between the action and close buttons
    • Esc dismisses a focused, dismissible toast
    • Enter runs the action, then closes

    05 · Get started

    Two lines to your first toast.

    No stylesheet to import, no provider to wrap, no container to mount. Install it from GitHub, or copy the single file into your project.

    1. Install

      Straight from the repository.

      npm i github:ghanemja/tiny-toast

    2. Import and call

      The first call injects the CSS and creates a labelled live region.

    3. Theme it (optional)

      Override the --tt-* custom properties on :root. Dark mode follows prefers-color-scheme out of the box.

    import toast from 'tiny-toast';

toast('Saved!');
toast.success('Profile updated');
toast.warning('Battery low');
toast.error('Upload failed', { duration: 0 }); // sticky
    import toast from 'tiny-toast';

// A progress toast you close yourself
const t = toast('Uploading…', { duration: 0, dismissible: false });
await upload(file);
t.dismiss();
toast.success('Upload complete');

// An action button (the toast closes after onClick)
toast('Message deleted', {
  action: { label: 'Undo', onClick: () => restore() },
});

// Defaults for every later toast
toast.configure({ position: 'top-center', duration: 5000, max: 5 });
toast.dismissAll();
